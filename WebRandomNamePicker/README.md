# 点名大师 - 极简随机点名器 v2.1

基于原版网页版随机点名器的全面升级版本，针对用户反馈进行了三大核心功能改进。

## 🚀 新增功能

### 1. **文件导入功能**
- **TXT文件导入**：支持每行一个名字的TXT文件导入
- **Excel兼容**：提供详细的Excel文件转换指导（另存为CSV/TXT格式）
- **智能解析**：自动过滤空行、注释行和非姓名内容
- **灵活导入选项**：
  - 创建新小组导入
  - 追加到当前小组

### 2. **两种抽取模式**
- **动画模式**：传统的滚动动画效果，增加趣味性
- **直接模式**：一键立即显示结果，快速高效
- **模式切换**：通过开关轻松切换两种模式

### 3. **极简UI设计**
- **主界面简化**：只保留核心功能，界面更清晰
- **设置面板集成**：所有高级功能集成到设置面板中
- **响应式设计**：完美适配桌面和移动设备

## 🎨 界面布局

### 极简主界面
- **头部**：Logo + 设置/主题切换按钮
- **小组信息卡**：显示当前小组和成员数量，提供快速导入/切换按钮
- **核心显示区**：点名结果显示区域，包含模式切换开关
- **操作按钮**："开始抽取"（动画模式）和"快速点名"（直接模式）
- **快捷统计**：总次数、已点、剩余三个关键统计指标

### 设置面板（二级弹窗）
- **文件导入区**：TXT文件导入功能和Excel转换指导
- **小组管理区**：小组列表查看、创建、编辑、删除
- **历史记录区**：最近记录预览和完整历史查看
- **其他设置**：自动保存、提示音效、完成通知等选项

## 🔧 使用指南

### 基础使用
1. **启动应用**：打开 `index.html` 文件
2. **选择模式**：切换"动画/直接"模式开关
3. **开始点名**：点击"开始抽取"（动画模式）或"快速点名"（直接模式）

### 文件导入步骤
1. **准备文件**：创建每行一个名字的TXT文件
2. **导入文件**：点击"导入名单"按钮选择文件
3. **选择方式**：
   - 点击"确定"：创建新小组
   - 点击"取消"：追加到当前小组

### Excel文件支持
1. 在Excel中选择"文件" → "另存为"
2. 选择"CSV (逗号分隔)"或"文本文件(制表符分隔)"
3. 保存后使用TXT导入功能

### 小组管理
- **创建小组**：点击"新建小组"按钮
- **编辑小组**：点击"编辑当前"按钮修改当前小组
- **切换小组**：在设置面板中点击小组列表
- **删除小组**：点击小组旁边的删除按钮（默认小组不可删除）

### 历史记录
- **查看历史**：点击"查看全部"查看完整记录
- **清空历史**：点击"清空历史"按钮
- **导出历史**：点击"导出历史"下载为TXT文件
